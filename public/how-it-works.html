Changelog

A running log of updates, fixes, and improvements to APS AI. Entries are listed in reverse chronological order. If something here affects how you use the product, we’ll call it out plainly in the notes for that release.

November 2026

Nov 14 — Initial public release

Release Web

This is the first public version of APS AI. The goal for this release was simple: ship a clean, dependable starting point rather than a long list of half-finished features. What’s included today is the core web experience, the basic information pages, and the underlying setup needed to serve the site reliably.

Highlights in this release:

  • Launched the main APS AI site with a streamlined layout focused on clarity and speed.
  • Added an overview of how APS AI works and what it’s meant to help with.
  • Set up hosting and asset delivery so pages load consistently across devices.
  • Established this changelog as the place where we’ll record notable changes going forward.

Known limitations: this is an early release, so you may notice rough edges in copy or layout on smaller screens. We’re collecting feedback and will prioritize fixes based on what people actually run into.

Nov 10 — Preview build

Preview

Shared a private preview build for internal testing. The focus during this phase was checking content accuracy, basic navigation, and performance on common browsers. Feedback from the preview informed the copy and structure changes that shipped in the public release.

Coming up

Near-term work is centered on polish and documentation: clearer explanations of features, better coverage of common questions, and small usability improvements based on early feedback. When those changes ship, they’ll be documented here with dates and short notes on what changed and why.
